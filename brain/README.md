# Synthetic Brain Architecture

This package is a whole-brain-inspired computational architecture. It models functional analogues of neural processing, memory, attention, affect, personality, self-modeling, learning, language, action selection, and homeostasis.

It is an engineering and research framework, not a claim of human consciousness or biological equivalence.

## Layers

- `neural/` — neurons, synapses, signals, plasticity, neuromodulation.
- `regions/` — functional analogues of cortex and subcortical systems.
- `networks/` — large-scale functional networks.
- `cognition/` — perception, attention, working memory, reasoning, planning.
- `affect/` — emotions, mood, reward, stress, curiosity, social affect.
- `identity/` — personality, values, beliefs, preferences, autobiographical self.
- `consciousness/` — global workspace, introspection, metacognition, subjective-state models.
- `learning/` — supervised, reinforcement, imitation, continual and skill learning.
- `language/` — semantics, pragmatics, dialogue and internal language.
- `homeostasis/` — arousal, energy, sleep and internal regulation.
- `embodiment/` — body state, proprioception, sensors and actuators.

The runtime should treat these as cooperating modules with explicit state and event interfaces rather than as a literal simulation of every biological neuron.
