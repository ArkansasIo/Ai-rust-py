# Synthetic Brain Architecture

This repository is the **Synthetic Brain Architecture** project.

## Project identity

- Project name: Synthetic Brain Architecture
- System name: human.brain
- Repository lineage: Ai-rust-py
- Primary languages: Rust and Python
- Hardware: custom modular PCB architecture
- Neural transport: Neuro-Link
- Prototype skull envelope: 220 × 180 × 170 mm
- Regional cartridge envelope: 120 × 80 × 25 mm
- Regional compute modules: 12

## Scope

The project combines a distributed synthetic-cognition software stack with a custom modular compute platform. The twelve regional cartridges share a mechanical, electrical, thermal, service, and firmware contract while allowing region-specific compute and accelerator configurations.

## Regional architecture

1. Brainstem — deterministic control and safety
2. Thalamus — routing and sensory fusion
3. Cerebellum — real-time motor learning
4. Hippocampus — memory-heavy processing
5. Amygdala — low-latency salience and affect
6. Basal Ganglia — decision and reward processing
7. Frontal — executive and high-performance cognition
8. Parietal — spatial and sensor fusion
9. Temporal — language, audio, and association
10. Occipital — vision processing
11. Motor — deterministic actuation
12. Somatosensory — tactile and proprioceptive fusion

## Hardware status

The current hardware files are an engineering draft and architecture specification. They are not manufacturing-qualified PCB layouts. Exact processor, accelerator, memory, PMIC, connector, signal-integrity, thermal, and power components must be selected and validated before fabrication.

## Rename policy

The canonical project name in new documentation is **Synthetic Brain Architecture**. Existing historical paths and Git history may retain `Ai-rust-py` until the GitHub repository itself is renamed through GitHub repository settings/API.
